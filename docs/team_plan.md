# 팀 프로젝트 계획

## 목표
쇼핑몰 주문 데이터를 분석하여 핵심 지표(매출, 인기 상품, 고객 구성 등)를 도출하고,
Streamlit 대시보드로 시각화한다.

## 역할 분담

- **A (데이터 점검 및 분석)**: 원본 데이터 점검, 결측치/이상치 처리, 데이터 분석
- **B (Streamlit 앱 및 시각화)**: 대시보드 UI 구현, 차트 시각화
- **C (통합, 테스트 및 문서화)**: 문서 관리, 브랜치 통합, 테스트, 발표 자료

## 일정 (예시 — 팀 회의 후 수정)

| 주차 | 내용 |
|---|---|
| 1주차 | 데이터 점검, 폴더 구조 세팅 |
| 2주차 | 데이터 분석, 초기 대시보드 구현 |
| 3주차 | 통합, 테스트, 문서 정리 |
| 4주차 | 발표 준비 |

## 커뮤니케이션 규칙

- 작업 시작 전 담당 브랜치를 생성한다.
- 매 작업 종료 시 `docs/work_log.md`에 한 줄 기록한다.
- PR은 최소 1인 이상의 리뷰 후 merge한다.
