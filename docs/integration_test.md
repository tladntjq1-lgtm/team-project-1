## 체크리스트

- [ ] `data_loader.py`가 4개 원본 CSV를 정상적으로 불러오는가
- [ ] `analysis.py`의 함수들이 예외 없이 동작하는가
- [ ] `app.py` 실행 시 오류 없이 대시보드가 뜨는가
- [ ] `charts.py`의 차트가 실제 데이터로 정상 렌더링되는가
- [ ] 결측치/이상치 처리가 최종 데이터에 반영되었는가
